How to Use This Resource Library

Different materials serve different scientific purposes.

For the current scientific status

Use the Research Program page. It is the living status layer and should control how older technical resources are interpreted.

For citable claims

Use the DOI-backed papers, datasets, monographs, and archives listed on Publications .

For reproducibility

Prefer frozen computational archives, source bundles, machine-readable ledgers, manifests, verifier outputs, and preregistered gate records.

For conceptual orientation

Use QDL in 5 Minutes and the graphical abstracts.

For historical branches

Older QDL papers and graphics remain useful as development records but should not automatically be interpreted as the program's current strongest formulation.

For independent replication

Use the frozen research archives and preregistered controls rather than reconstructed descriptions from later summaries.
