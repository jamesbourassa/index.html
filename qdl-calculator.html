Three Different Mathematical Questions

1. Full QDL rank-four closure (five-axis ledger only):

C(v) = 2(L₁ + L₂ + L₃) − 3(F₁ + F₂) = 0

This condition defines an integer lattice of rank four, not a one-dimensional line.

2. Exact chosen-subgroup membership:

v = kq, where k is an integer

With the default q = (1,1,1,1,1), this is strictly narrower than full closure.

3. Real proportionality to a direction:

v = αq, where α is a real number

With integer input vectors, proportionality is tested exactly using integer cross-products, not floating-point tolerance.

Worked distinction: v = (2,0,1;1,1) gives C(v) = 0, but is not a multiple of q = (1,1,1,1,1). A result that fails the subgroup test must not be described as failure of full closure.
