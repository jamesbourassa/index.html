Quantized Dimensional Ledger (QDL)

The QDL Physics Institute develops the Quantized Dimensional Ledger, a structural dimensional-closure framework that treats dimensional analysis as a model-admissibility constraint. The program explores applications across EFT structure, gravitation, metrology, and falsifiable precision experiments.

Explore the Research Program Read the Papers

Framework

QDL represents physical quantities as integer vectors in a dimensional lattice with closure constraints on admissible constructions.

Prediction Filtering

The framework functions as a structural admissibility filter that can restrict EFT operator structure and model representations before phenomenological fitting.

Experimental Tests

The program proposes falsifiable experimental tests including torsion balance scaling, NV-center protocols, cavity resonators, and metamaterials.
